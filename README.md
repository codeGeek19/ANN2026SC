# LVQ Energy Prediction Model

## Description
This project implements a Learning Vector Quantization (LVQ) model to predict energy-related outputs based on input features.

## Tech Stack
- Python
- NumPy
- Scikit-learn
- Flask 

## Features
- Trained LVQ model for prediction
- Model saved using .pkl file
- Basic API (app.py) for inference

## How to Run
1. Install dependencies
2. Run app.py
3. Provide input data for prediction

## Status
Basic implementation (work in progress)
